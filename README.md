# BTTP Website

Marketing website for BTTP, built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Project Structure

- `src/app/` — routes: home (`/`), `point-calculator`, `pricing`, `blog`
- `src/components/layout/` — shared `Navbar` and `Footer`
- `src/components/home/` — home page sections (currently placeholders, to be filled in)

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` — run ESLint
